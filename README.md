## 当前收录

- [problem-driven-architecture-analysis](problem-driven-architecture-analysis/SKILL.md)：从项目目标和问题链路出发，分析架构路线、生态位置与具体实现。

仓库中的目录是版本管理副本。将所需目录安装到本机 Codex skills 目录后即可使用；本机已有的安装副本不会因仓库更新而自动同步。
